# プライバシーポリシー（個人用ツール）

- このツールは作者本人だけが自分の PC で使う。ほかの人のデータを集めない・送らない。
- 保存するもの：本人が入力した動画 URL・本人のメモ・本人が確認した要約・本人の分析。
- YouTube Data API から取得した値（動画 ID・タイトル・公開日・チャンネル ID）は**保存しない**。本人が実行したその回の画面表示にだけ使い、終わったら捨てる（ファイル・ログ・レポートに残さない）。
- 古い版が保存した API の値があれば、ツールを起動するたびに自動で削除する。
- 外部への送信はしない（API への問い合わせを除く・承認後）。
- YouTube API Services を使う場合は、YouTube 利用規約（https://www.youtube.com/t/terms）と Google プライバシーポリシー（https://policies.google.com/privacy）が適用される。
- 削除したいとき：`data/` フォルダを消せばすべて消える。
